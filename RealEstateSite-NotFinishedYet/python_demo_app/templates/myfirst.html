Python Artificial Intelligence - Optimization


Problem:
Given a geographic area, calculate the optimal location for a brand new EV charging station. The location should service the geographic area as fairly as possible.

Solution:
Use Python to calculate a latitude/longitude coordinate which is central to the geographic area. Then display it on a map.

Algorithm:
  1. Use Python's Geopy library to geocode addresses within New Jersey. This assigns latitudes & longitudes to each address.
  2. Use a custom Haversine function to calculate the distances from each coordinate to all other coordinates.
  3. For each coordinate, calculate the distance from that coordinate to all coordinates.
  4. Select the coordinate with the lowest maximum distance to all other points. This will be the coordinate which is central to all coordinates.
  5. Use Python's Folium library to map each coordinate in red on the map.
  6. Use Python's Folium library to map the solution, the central point, in green on the map.
